# Validation of the external rebuild guide

Status: Christopher's clarification, relayed on 2026-09-10 through the local
task `Check issue 45 progress (2)`, task ID
`01a071cf-399b-7712-8409-461f1ad4746a`.

For [Implement and verify the agreed MWF 0.6.2 workflow-management changes](https://github.com/Christopher8187/product/issues/45),
actually rebuilding an older or example project is not a required check,
completion criterion, or prerequisite for final review. This also applies to a
rebuild trial delegated to another agent. The earlier suggestion that examples
could be tested did not make such a trial mandatory.

Requirement 45-SM-004 still requires the [external guide](../../../../migration.md)
to describe the completed runtime accurately, receive appropriate documentation
and source review, and state its actual validation limits. Its unexecuted
walkthrough must not be recorded as missing required work.

All required native runtime checks remain in force. This clarification does
not authorize repairs to examples or changes to older projects.
